# MMLang

mobius-programming-machine-language

新的机器，以及新的esolang

融合了图灵机、冯·诺伊曼机、哈佛架构、BrainFuck，一些有趣的新特性，以及一些奇奇怪怪的东西。在探究计算机发展史的时候，我创造了它。

这台机器被叫作莫比乌斯机，它的专属编程语言被称为莫比乌斯机编程语言

我很难相信这鬼东西居然是图灵完备的
