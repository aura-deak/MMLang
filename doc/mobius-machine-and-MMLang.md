## 莫比乌斯机

莫比乌斯机是一种图灵机变体，读写头在无限长的数字数据纸带上双向移动。机器分为程序纸带和数据纸带。

指令通过程序纸带送入，程序纸带单向顺序只读，通过物理连接程序纸带两端实现程序循环，这种循环是可选的

程序纸带按序列轮回调度，如一个三程序纸带的序列，换带按照1、2、3、1的顺序。若只有单个程序纸带，则执行换带指令为从头执行自身。

当执行换带指令时，停机，保留当前读写头位置和数据纸带数据，切换到下一个程序纸带开始从头读取，而上一条程序纸带的PC状态丢失

可以在程序开始前向队列里插入任意数量的程序纸带，程序开始后则只能由程序自身向队列里添加程序纸带

支持将当前的数据纸带从读写头右侧截断，取截下来的左侧数据纸带片段作为新的程序纸带插入当前程序纸带的下一位，此时读写头上没有程序纸带。该截断指令执行后、下一条指令执行前会自动回到当前程序纸带的开头。

该机器支持回卷指令，执行后回退到数据纸带的开头,这让内存地址成为可能。

# 莫比乌斯机编程语言

| 助记符 | 二进制    | 描述                                                                                      |
| :-- | :----- | :-------------------------------------------------------------------------------------- |
| `>` | `0000` | 数据读写头向右移动一格                                                                             |
| `<` | `0001` | 数据读写头向左移动一格                                                                             |
| `x` | `0010` | 翻转当前数据格（0变1，1变0）                                                                        |
| `f` | `0011` | 若当前格为0，正常执行下一条指令；若为1，跳过下一条指令（PC+2）                                                      |
| `s` | `0100` | 换带停机：挂起当前程序纸带，丢弃PC，切换到调度队列下一条程序纸带（新带从头读取）；数据纸带和读写头位置完全保留                                     |
| `b` | `0101` | 全局停机：终止整个系统，将当前整条数据纸带从读写头右侧截断，取截下来的左侧数据纸带片段作为最终计算结果输出                                        |
| `p` | `0110` | 截断快照：从读写头右侧截断，将截断的数据纸带片段作为新的程序纸带，插入到程序纸带序列中当前程序纸带的后一位                                         |
| `n` | `0111` | 空操作                                                                                     |
| `l` | `1000` | **仅限程序纸带末尾**：实体机中看到此指令出现在末尾，需裁掉这4位，并将程序纸带头部拼接至尾部，形成物理闭环（运行时PC到头自动折返至开头）。在虚拟机中则保留此指令，作用为PC归零 |
| `r` | `1001` | 回退指令，执行后回退到数据纸带的开头,这让内存地址成为可能。**注意，p可能使数据的位置发生变化，因为数据纸带截短导致原点变化**                         |

大小写敏感。不在指令集内的视为注释

如用\[?]表示读写头，示范如下

**b指令**：\
原始数据`1111 11[1]0 000`\
输出数据`1111 111`，即右侧被抛弃

**p命令**：
原始数据`0000 0111 011[1] 1000`\
输出代码`0000 0111 0111`，为`>nn`，剩余的数据纸带与读写头为`[?]1000`，此时因为读写头下方没有数据纸带，所以该条指令执行后、下一条指令执行前dp会自动置零（即回到数据纸带的开头），使得下一条指令执行前数据纸带与读写头为`[1]000`

## 汇编期预处理特殊语法

| 符号 | 用途                                       |
| :- | :--------------------------------------- |
| \* | 重复语法。在预处理时会进行展开，如将`>*1024`展开成1024个>      |
| #0 | 程序纸带标注，出现在.mmlang和.mmbin当中,用于区分程序纸带。从0开始标号递增 |
| // | 注释，出现在.mmlang当中,用于注释代码 |
